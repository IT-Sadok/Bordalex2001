# Booking System API
An Airbnb clone with .NET backend.

## Overview

Backend API for managing bookings and scheduling, deployed on Azure.

## 🏗️ Tech Stack

- **Backend**: .NET 9, C#
- **Cloud**: Azure (Poland Central)
- **CI/CD**: GitHub Actions

## 🚀 Quick Start

### Backend

```bash
git clone https://github.com/IT-Sadok/Bordalex2001.git
cd Bordalex2001
dotnet restore
dotnet build --configuration Release
dotnet test --configuration Release
```

## 📋 Features

- Web API for booking management
- Automated testing and CI/CD pipeline
- Security vulnerability scanning
- Azure cloud deployment

## 🔄 CI/CD

GitHub Actions automatically:
- Builds and tests on push/PR to `dev` or `main`
- Runs security checks
- Publishes artifacts to Azure
